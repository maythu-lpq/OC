# 規格書：Organic Chemistry Reaction Mechanism Hub

> မြန်မာအကျဉ်း — SN1/SN2/E1/E2 ကို ခန့်မှန်း၊ အဆင့်လိုက်ကြည့်၊ လေ့ကျင့်နိုင်သော static web app (backend မလို၊ GitHub Pages မှာ တင်နိုင်)

## 1. 專案概要
| 項目 | 內容 |
|---|---|
| 名稱 | Organic Chemistry Reaction Mechanism Hub |
| 類型 | 純前端靜態網頁（HTML / CSS / JavaScript，無建置工具） |
| 目標使用者 | 有機化學初學者、大學一年級至二年級學生 |
| 目的 | 以三個互動模組學習 SN1、SN2、E1、E2 的判斷與機制 |
| 部署 | GitHub Pages（Settings → Pages → Branch: main / root） |

## 2. 檔案結構
```
organic-mechanism-hub/
├── index.html   頁面結構、載入 KaTeX（含 mhchem）、字體
├── style.css    可愛粉彩主題、響應式、動畫
├── script.js    判斷邏輯、機制資料、測驗題庫
└── 規格書.md    本文件
```
外部依賴（CDN）：KaTeX 0.16.11（katex、mhchem、auto-render）、Google Fonts（Fredoka、Noto Sans Myanmar）。

## 3. 功能規格
### 3.1 Predictor（判斷樹）
- 輸入：基質（甲基 / 1° / 2° / 3°）、親核試劑或鹼（4 類）、溶劑（質子性 / 非質子性）、溫度（室溫 / 加熱）。
- 輸出：主要機制、次要機制、白話說明、理由清單（v1.1 起不使用數學符號與公式）；可跳至 Visualizer。
- 規則摘要：

| 試劑 | 甲基 | 1° | 2° | 3° |
|---|---|---|---|---|
| 好 Nu、弱鹼 | SN2 | SN2 | SN2（次 E2） | 質子性 SN1/E1；非質子性 E2 |
| 強鹼 + 強 Nu | SN2 | SN2（加熱 E2） | E2（次 SN2） | E2 |
| 大體積鹼 | SN2 | E2 | E2 | E2 |
| 弱 Nu / 弱鹼 | 無反應 | 無反應 | SN1（加熱 E1） | SN1（加熱 E1） |

### 3.2 Visualizer（機制視覺化）
- 4 種機制，各 2–3 步；SVG 繪製物種、鍵、彎曲箭頭。v1.1：電子（黃點）沿箭頭跳動；斷鍵淡出、新鍵淡入；離去基（Br → Br⁻）跳出並彈向一側；「Replay」可重播。
- 每步附標題與 LaTeX 說明；上一步 / 下一步 / 步驟點。

### 3.3 Quiz Bot（測驗）
- 43 題，分 4 類：Pathway（14）、Product（7）、Concepts（15）、Stereo & shifts（7）；可選類別，非 Pathway 題的選項會隨機排列。
- 即時回饋：正誤、解釋、產物（mhchem 化學式）；累計分數與連續答對；結算畫面可「Retry missed」只重做答錯的題目。

## 4. 數學與化學式
- `$...$` 行內、`$$...$$` 獨立行；`\ce{...}` 為 mhchem 語法。
- 動態插入內容後必須呼叫 `math(element)` 重新渲染。

## 6. 非功能需求
- 無後端、無儲存；離線時需 CDN 可用（KaTeX 載入失敗則顯示原始 `$...$`）。
- 支援近兩年版本的 Chrome / Edge / Safari / Firefox。

## 7. 部署步驟
1. 建立 GitHub repo，上傳 `index.html`、`style.css`、`script.js`、`規格書.md`。
2. Settings → Pages → Source：Deploy from a branch → main / (root)。
3. 網址：`https://<username>.github.io/<repo>/`
