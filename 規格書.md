# [Specification Document / 規格書]

**Project Title:** Organic Chemistry Reaction Mechanism Hub

**Description:** An interactive, web-based educational platform for predicting, visualizing, and testing nucleophilic substitution and elimination reactions (SN1, SN2, E1, E2). It helps university students tell the four pathways apart by letting them try conditions, watch electrons move, and practise with questions.

---

## 1. Technical Architecture & Stack

- **Frontend:** A single `index.html` file that holds the page structure, the styling (responsive pastel theme), and the program logic (plain JavaScript, no frameworks or build tools).
- **Graphic Engine:** Inline vector graphics (SVG) for reaction mechanisms, curved arrows, moving electrons, and intermediate states.
- **Formula Display:** KaTeX, loaded online, to show chemical formulas neatly.
- **Hosting:** GitHub Pages (static site deployment).
- **Development Method:** Built with an AI assistant (Claude) through vibe coding and improved over several rounds.

## 2. Module Specifications

### Module 1: Mechanism Predictor (Decision Tree Engine)
- **Inputs:** Substrate (methyl, 1°, 2°, 3°), nucleophile/base type (4 types), solvent type (protic/aprotic), temperature (room temperature/heated).
- **Output:** Major and minor reaction path (SN1, SN2, E1, E2, or no reaction), a one-line plain-language explanation, and the reasons for the decision. A button opens the matching mechanism in Module 2.

### Module 2: Step-by-Step Mechanism Visualizer
- Shows SN1, SN2, E1, and E2 in 2–3 steps each, with transition states and intermediates.
- Curved arrows show electron movement: yellow electron dots hop along each arrow, old bonds fade, new bonds appear, and the leaving group (Br to Br⁻) jumps out and bounces to the side.
- Controls: Back, Next, and Replay.

### Module 3: Interactive Reaction Quiz Bot
- 43 questions in four categories: Pathway, Product, Concepts, and Stereochemistry & shifts. The user chooses a category first.
- Real-time score and streak tracking, immediate feedback with a chemical explanation, and a "Retry missed" option at the end.

### Module 4: FAQ
- 12 frequently asked questions about SN1, SN2, E1, and E2 (expandable answers) and a quick-reference cheat sheet.

## 3. User Interface

- Cute pastel design (pink, mint, lavender) with rounded buttons and a floating flask mascot.
- Four tabs for navigation; works on phones and computers.

## 4. Deployment

- Upload `index.html` to a public GitHub repository, then turn on GitHub Pages (Settings → Pages → main branch, root folder).
